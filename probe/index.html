OM Reader 測試頁

驗四件事：手機能不能存下全部資料、能不能從私有 repo 同步、Face ID 開啟鎖、能不能叫起 Notion App。 請先用 Safari「分享 → 加入主畫面」，從主畫面的圖示打開再測——主畫面 App 和 Safari 分頁的行為不同。

0　環境

1　手機儲存

正式 App 預計離線存約 300 MB。這裡寫入同樣大小的測試資料，隔幾天再打開，看資料還在不在。

2　從私有 repo 同步

用唯讀 token 直接呼叫 GitHub API。repo 名稱和 token 只存在這支手機，不寫進程式。

    3　Face ID 開啟鎖

    建立一把只屬於這個 App 的通行金鑰，再用 Face ID 解鎖。也順便測能不能從 Face ID 導出加密金鑰（PRF）——能的話，正式版可以把手機上的資料再加密一層。

      4　叫起 Notion App

      貼一個你自己的 Notion 頁面網址（筆記 frontmatter 的 notion_page 那種），點下面三個連結，各回報一次結果。

        5　結果

        全部測完後按「複製結果」，貼回給 Claude。內容不含 token、repo 名稱與 Notion 網址。
